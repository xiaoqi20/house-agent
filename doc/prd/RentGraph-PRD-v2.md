## 1. 产品概述

**产品名称**：RentGraph（租房合同风险雷达，一期定位）

**一句话定位**：
上传一份租房合同，Agent 在 60 秒内给出**可点击定位到条款原文**的风险报告，并附修改建议与谈判话术。

**核心价值**：合同看不懂 → 逐条翻译成人话；怕被坑 → 每条风险有规则依据；谈判没底 → 一键复制话术。

**目标用户**：中国大陆租房人群（22-35 岁城市白领），签约前 / 退租前两个高意愿时刻。

**商业模式**：Freemium。一期免费做口碑与数据积累，Phase 2 再验证付费（模板库、纠纷模拟）。

## 2. 产品形态：对话即产品

**核心变更（对齐原型）**：一期砍掉"仪表盘 + 多面板工作台"，产品只有一个界面——**屏幕正中心的对话框**。

- 首页 = 居中问候 + 大输入框 + 3 个快捷指令（审查合同 / 违约金怎么谈 / 押金不退）
- 所有功能通过对话触发，结果以 **inline 卡片** 嵌入消息流：
  - 解析进度 checklist 卡（实时步骤勾选）
  - 风险雷达报告卡（分级、条款溯源、操作按钮）
- 合同原文 = **右侧滑出抽屉**，风险条款黄色高亮，从报告卡点击跳转定位
- 侧边栏仅保留：新建分析、对话工作台、我的合同、最近对话

不再做：Dashboard 指标卡、图谱预览、独立的功能面板页（图谱/时间线/风险雷达/纠纷模拟）。二期若有需要，以"生成式 UI 面板"形态在对话内展开。

## 3. 一期功能（MVP）

| # | 功能 | 说明 | 验收 |
|---|------|------|------|
| 1 | 合同导入 | 粘贴文本 / 上传 PDF（文字层提取） | 5 页合同 ≤10s 完成解析 |
| 2 | 条款抽取 | 结构化：条号/类型/原文/金额/日期/当事人 | schema 校验通过率 ≥95% |
| 3 | 风险雷达 | 规则库 + LLM 兜底，输出高/中/低风险卡 | 每条风险 grounding 到条款 id |
| 4 | 原文定位 | 点击风险 → 抽屉内高亮对应条款 | 定位准确率 100% |
| 5 | 谈判话术 | 一键复制发给房东的修改建议 | 话术含具体条号与替换文本 |
| 6 | 智能问答 | 引用条款原文回答，含历史对话 | 不引用不存在的条款 |
| 7 | 免责设计 | "不构成法律意见" 全局可见 | 输入框下方固定文案 |

评测（必须交付的数字）：20 份人工标注合同，端到端风险查准 ≥70%、查全 ≥80%。

## 4. 页面规格（以原型为准）

**布局**：1080p 桌面优先，`h-screen` 三区结构。

| 区域 | 规格 |
|------|------|
| 左侧栏 | 240px，`hidden md:flex`（窄屏隐藏），灰底 #F9FAFB |
| 主区 | 空态：居中 hero（图标+问候+输入框+快捷指令）；对话态：max-w-3xl 消息流 + 底部 dock 输入框 |
| 合同抽屉 | 右侧滑出，max-w-md，translate-x 过渡 300ms，带遮罩 |
| 顶栏 | 56px，标题 + Agent 在线状态点 |

**关键组件**：
- 输入框：白底圆角 2xl，focus 时边框加深 + 阴影；回车上滑下换行；空内容不可发送；内容 HTML 转义防 XSS
- 风险卡：等级徽章（高=红 50/中=琥珀 50）+ 条号 + 一句话依据 + 右箭头；hover 变灰
- 解析进度：未完成灰圈 → 进行中 spin → 完成绿勾，逐条推进
- Toast：底部居中深色胶囊，2.2s 自动消失

**视觉规范（修正旧版"深蓝+橙"）**：
- 主色：品牌青绿 teal `#0D9488`（仅用于 logo/点缀图标）；操作按钮与用户消息统一深灰近黑 `#111829`
- 语义色：风险红 `#DC2626`、警示琥珀 `#D97706`、成功绿 `#16A34A`
- 字体：Inter + PingFang SC 回退；正文 13px，标题 15-30px
- 圆角大一档：卡片 2xl，徽章 md；边框优先于阴影做层级

## 5. 技术架构

**一期（前后端分离，详见 `doc/arch/技术栈选型-前后端分离.md`）**：
- 前端：Vite + React 18 + TS + Tailwind + shadcn/ui（SPA，无 SSR 需求，不用 Next.js）
- 后端：Python 3.12 + FastAPI + Pydantic v2；Postgres 16（contracts / clauses / risks 三表，JSONB 存抽取结果）
- LLM：OpenAI SDK 统一接入，主 DeepSeek-V3、备 Qwen-Plus，JSON Schema 强约束抽取；不引 LangChain
- 实时：SSE（解析进度 + 流式回答）；鉴权：手机验证码 + JWT
- 部署：单仓双目录 monorepo（web/ + server/），Docker Compose 单机

**二期再上**：Neo4j（条款表即图谱原料，零迁移成本）、向量库（跨合同检索时）、React Flow（图谱可视化）、OCR、任务队列。

## 6. 后续阶段

- **Phase 1**：个人合同库管理（列表/对比两份合同）、时间线提醒（续租/押金退还日 push）、房源 Checklist
- **Phase 2**：知识图谱可视化、纠纷模拟、合同模板库、房东坑点库、室友协作、付费

## 7. 已知风险

| 风险 | 对策 |
|------|------|
| 租房低频 → 留存差 | 一期不考核 DAU，考核"分享报告"次数与口碑 |
| AI 法律建议边界 | 全链路免责 + 每条结论附规则依据，可申诉 |
| PDF 提取失败 | 失败即引导粘贴文本，不阻塞主流程 |
