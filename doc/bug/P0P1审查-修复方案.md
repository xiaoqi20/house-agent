## 必须修（演示会断或答错合同）

### B1 侧栏打开合同，追问仍问上一份

- **现象**：点「我的合同」看合同 B，再问「违约金怎么谈」，答的是会话里的合同 A。
- **原因**：[Sidebar.tsx](../../web/src/components/Sidebar.tsx) 对 `done`/`failed` 只调 `openContract`（开抽屉），不写 `store.contractId`。[chatStore `ask()`](../../web/src/stores/chatStore.ts) 仍带旧 id。
- **修法**：侧栏点击已完成合同时同时 `set({ contractId: c.id })`；可选再加载该合同风险卡到当前会话。抽屉与追问必须指向同一份合同。
- **验收**：两份合同，点侧栏 B 再追问，回复 `contract_id === B`，cite 打开 B 的抽屉。

### B2 省略 `contract_id` 时后端回落到最新 done

- **现象**：首页快捷卡片、新建分析清空 id 后提问，HTTP 200 绑到库里上一份演示合同。
- **原因**：[chat.py `_load_contract`](../../server/src/rentgraph/api/chat.py) 中 `contract_id` 可选；未指定则 `status==done` 按 id 倒序取 1。测试只覆盖了「传了 id」。
- **修法**：产品路径省略 `contract_id` 返回 422（「请先完成一份合同审查」），禁止静默绑最新合同。curl 调试如需回落，用显式 query 如 `fallback=latest`，默认关闭。
- **验收**：空 `contract_id` + 库里已有 done 合同 → 4xx，不出现那份合同的条款原文。

### B3 分析未完成就追问 → 404

- **现象**：checklist 等待期间提问，得到「尚未完成分析」。
- **原因**：`analyzeContract` 一开始就把 `contractId` 设成正在分析的那份；`_load_contract` 要求 `status == done`。
- **修法（二选一，推荐都做）**：
  1. 前端：`status !== done` 时禁用输入或拦截 `ask`，提示「请等分析完成」。
  2. 后端：对 `analyzing` 返回 409 + 明确文案，不要用和「不存在」混在一起的 404。
- **验收**：分析进行中发「违约金怎么谈」→ 人话提示等待，不出现 404 堆栈感文案；分析 `done` 后同一句能引用条款。

### B4 含「第 N 条」且 ≥50 字的追问被当成新合同

- **现象**：临场发挥「请根据第8条原文说明违约金怎么跟房东谈，再给一句发给房东的话」会 `POST /contracts` 再抽一次。
- **原因**：`isContractPaste` = `len≥50 && (len≥300 || 第N条)`。首页还写「50 字以上直接分析」，与真实规则不一致。
- **修法**：已有当前 `contractId` 时，中短句（建议 <300 字）一律走问答；仅无当前合同、或 ≥300 字才当粘贴合同。首页文案改成与规则一致。
- **验收**：分析完成后粘贴带「第8条」的 80 字追问 → chat，不新建合同、不出现第二份 checklist。

### B5 「新建分析」不取消进行中的分析

- **现象**：等进度时点新建，下一轮对话冒出上一份合同的风险卡。
- **原因**：`reset()` 清消息和 `contractId`，无 AbortController / generation token；SSE `done` 后仍 `push` 报告。
- **修法**：为每次 `analyzeContract`/`ask` 递增 `runId`（或 AbortController）；`reset` 时作废旧 run，回调里 `if (runId !== current) return`。
- **验收**：分析中途点「新建分析」再上传另一份，消息流里不得出现上一份的报告卡。

## 次要（有空再做）

- 分析接口拒绝 `raw_text=""` 的图片，避免空跑模型并覆盖 OCR 提示
- 短文字层 PDF（&lt;200 字）用 `TEXT_TOO_SHORT`，不要标成扫描件；坏 PDF 捕获为 422 而非 500
- SSE 无 `done`/`error` 时收尾为失败气泡，checklist 不得永转
- 失败气泡不要用绿色 `CircleCheck`
- 测试：省略 `contract_id` 必须 4xx；去掉 `test_p0_gaps.py` 里重复的 `NO_CLAUSE_TEXT` 和空的 `assert OpenAI`
