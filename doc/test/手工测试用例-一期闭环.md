## 0. 开始之前

| 步骤 | 命令 / 操作 | 预期 |
|---|---|---|
| 起库 | `cd server && docker compose up -d db` | `rentgraph-pg` 为 healthy |
| 起后端 | `cd server && .venv/bin/uvicorn rentgraph.main:app --port 8010 --reload` | `curl -s localhost:8010/healthz` 返回 `"ok":true` |
| 起前端 | `cd web && pnpm dev` | 打开 http://localhost:5273 见首页 |
| 清库（建议） | `docker exec -it rentgraph-pg psql -U rentgraph -d rentgraph -c 'TRUNCATE contracts CASCADE;'` | 侧栏「我的合同」计数为 0 |

**单条用例的粘贴格式：两行，先标题再条款**（否则不足 50 字会被当前端门槛判成提问）：

```text
房屋租赁合同
<下面表格里的「输入」原文>
```

**§5/§6/§7/§9 共用的整份演示合同**（记为 `合同F`）：

```text
北京市房屋租赁合同
第一条 租赁房屋 甲方将位于北京市朝阳区望京街道某小区 3 号楼 1202 室房屋出租给乙方居住使用，建筑面积 68.5 平方米。
第三条 租赁期限 租赁期共 12 个月，自 2026 年 9 月 15 日起至 2027 年 9 月 14 日止。
第四条 租金 月租金为人民币 6,500 元，按押一付三方式支付，乙方应于每期开始前 7 日支付。
第六条 押金 乙方于签约当日支付房屋租赁押金人民币 6,500 元。租赁期满，房屋及设施无损坏的，甲方退还押金。
第八条 违约责任 任何一方违约的，应向守约方支付违约金，违约金金额为月租金的三倍，并赔偿由此造成的全部损失。
第十条 房屋维修 租赁期内，因乙方使用不当造成的房屋及设施损坏，由乙方负责维修或赔偿。
第十二条 续租 租赁期届满前 30 日内乙方未书面通知甲方不续租的，视为自动续租一年，续租期间租金在上一年度基础上上浮 5%。
```

**合同F 的权威预期**（一切「报告/抽屉/导出」用例以此为准）：条款 **7** ／ 风险 **7**（高3 中3 低1）／ 健康度 **43** ＝ `第4条 unclear-fees(低)`、`第6条 deposit-no-deadline(高)+deposit-vague-damage(高)+no-handover(中)`、`第8条 over-penalty(高)`、`第10条 repair-inverted(中)`、`第12条 auto-renewal(中)`。

## 10. 已知限制（**不要报 bug**）

| 现象 | 说明 |
|---|---|
| 部分 PDF 抽取后条款数少于原文（如 `cupsfilter` 转出的 PDF，`第一条` 变成 `第⼀条`） | PDF 文本里的兼容汉字（Kangxi Radicals）导致条号/条名识别失败 → 属 §2「真实合同 ingest」待办，一期不修，**记录即可** |
| <50 字粘贴 422 时气泡可能是英文 `String should have at least 50 characters` | 校验消息未本地化；正常路径前端已拦截 |
| 抽屉不支持 ESC 关闭，需点遮罩/✕ | 已知体验小坑 |
| 刷新后对话消失，侧栏合同仍在 | 一期无会话持久化（`contractId` 只在内存） |
| 侧栏会看到 pytest/冒烟留下的测试合同 | dev 库共用；演示前按 §0 清库 |
| Word、图片 OCR、登录、多租户、真 PDF 导出、40 条规则 | 一期方案 §5 明确延后 |

### 附录：无文字层 PDF 生成脚本

```bash
python3 - <<'PY'
objs=[b"<< /Type /Catalog /Pages 2 0 R >>", b"<< /Type /Pages /Kids [3 0 R] /Count 1 >>",
      b"<< /Type /Page /Parent 2 0 R /MediaBox [0 0 595 842] /Contents 4 0 R >>"]
s=b"q 1 0 0 rg 0 0 595 842 re f Q"; objs.append(b"<< /Length %d >>\nstream\n%s\nendstream"%(len(s),s))
out=bytearray(b"%PDF-1.4\n"); offs=[]
for i,b in enumerate(objs,1): offs.append(len(out)); out+=b"%d 0 obj\n"%i+b+b"\nendobj\n"
x=len(out); out+=b"xref\n0 %d\n"%(len(objs)+1)+b"0000000000 65535 f \n"
for o in offs: out+=b"%010d 00000 n \n"%o
out+=b"trailer\n<< /Size %d /Root 1 0 R >>\nstartxref\n%d\n%%%%EOF\n"%(len(objs)+1,x)
open("/tmp/scanned.pdf","wb").write(bytes(out)); print("wrote /tmp/scanned.pdf")
PY
```

带文字层 PDF（macOS）：`textutil`/编辑器把 `合同F` 存成 `/tmp/contract.txt` 后 `cupsfilter /tmp/contract.txt > /tmp/contract.pdf`（注意 §10 第 1 条的兼容汉字坑）。
